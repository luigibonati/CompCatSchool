# Dynamic Active Sites

This tutorial identifies dynamic active sites on Fe(111) and relates them to
N2 dissociation. It combines geometric surface detection, a PLUMED
environment-similarity descriptor, OPES reweighting, committor analysis, and
SOAP-based environment discovery.

## Workflow

1. Read the Fe trajectories and the chi7 reference environment with ASE.
2. Identify dynamically exposed upper-surface Fe atoms with OVITO.
3. Compute `ENVIRONMENTSIMILARITY` with PLUMED.
4. Count chi7-like sites and estimate their lifetimes in non-reactive
   trajectories.
5. Analyze the Fe environment around N2 in reactive OPES trajectories.
6. Compare geometric and committor-selected transition-state ensembles.
7. Discover and cluster surface environments with SOAP descriptors.

The main tutorial is [active_sites.ipynb](active_sites.ipynb).

## Contents

- `active_sites.ipynb`: complete analysis workflow and exercises.
- `data/300K/` and `data/700K/`: non-reactive Fe trajectories.
- `data/N2/`: reactive N2 trajectories and OPES weights.
- `data/committor/`: archived committor snapshots at 300 K and 700 K.
- `data/alphaprime_environment_bulk.xyz`: chi7 reference environment.

Surface-selected trajectories, PLUMED inputs and outputs, extracted committor
snapshots, and SOAP exports are generated by the notebook and are not stored in
the repository.

## Installation

Use the general `compcatschool` environment described in the
[repository README](../README.md#install). The active-sites tutorial uses the
same environment as the other sections; no separate environment is required.

Install the Python requirements after activating that environment:

```bash
pip install ase numpy pandas matplotlib ovito dscribe scikit-learn jupyterlab
pip install hdbscan  # optional
```

PLUMED must be available in `PATH` and include the `envsim` and `opes` modules.
HDBSCAN is optional; the notebook uses K-means when it is unavailable.

## Running

Activate PLUMED in the same shell used to start Jupyter. For a source build:

```bash
source /path/to/plumed-2.10.0/sourceme.sh
plumed info --version
```

Then start Jupyter from this folder so that all relative paths resolve
correctly:

```bash
cd 4_active_sites
jupyter lab
```

The reactive analysis uses the first 250 stored frames by default to keep the
classroom runtime manageable. Set `MAX_REACTIVE_FRAMES = None` in the notebook
to process the full trajectories.

## Generated Files

The notebook creates caches beside the input data. Delete those generated files
or set the corresponding `FORCE_RECOMPUTE_*` option in the notebook to repeat
OVITO or PLUMED calculations from scratch.
